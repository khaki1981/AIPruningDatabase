# SVG作図ガイドライン

- SVGは書籍挿絵のコピーではなく、伝える意味を整理した独自作図とする。
- 線、記号、切断位置、花芽、葉芽などの表現ルールを統一する。
- テキストをSVGへ直接埋め込みすぎず、可能な説明は植物JSON側で管理する。
- アクセシビリティのため、用途に応じて `aria-label` または `title` と `desc` を付ける。
- スマートフォンでの表示を前提に、適切な `viewBox` を設定する。
- 情報を色だけに依存させず、必要に応じて形や線種でも区別する。
- 植物JSONからSVGファイルの相対パスを参照する。
- SVGコードを植物JSONへ直接埋め込まない。
